ОТЧЁТ О РАБОТЕ С АГЕНТАМИ

Какие задачи ставились
Kilo Code и Copilot CLI: анализ кода (ANALYSIS.md), восстановление требований, модернизация и запуск приложения, новая функциональность.

Основные промпты
Kilo Code: «Проанализируй проект: стек, структура, компоненты, модель данных, работа с БД. Оформи в Markdown»; «Восстанови функциональные требования списком с подтверждением в коде»; «Модернизируй, исправь ошибки, запусти приложение».
Copilot CLI: «Дай обзор кодовой базы: что делает приложение, компоненты, взаимодействие. Укажи файлы»; «Проанализируй стек, структуру, модель данных, работу с БД. Оформи в Markdown».

Ошибки и проблемы
Kilo Code: пытался читать системные папки вне проекта; ошибка рендеринга промпта в бесплатном режиме; нерабочие кнопки.
Copilot CLI: зависания (команды вставали в очередь); недоступен выбор конкретной модели, только Fusion; нерабочие кнопки.

Корректировки
Kilo Code: добавил в промпт «работай только с файлами проекта.
Copilot CLI: перезапуск сессии и очистка очереди при зависании; переключение на /model fusion.

Как проверялись результаты
Сверка названных библиотек с файлами зависимостей; ручной запуск приложения и проверка адреса; проверка новых элементов и сохранения данных.

Время и итерации
Kilo Code: ~1 час.
Copilot CLI: ~2 часа.



СРАВНИТЕЛЬНЫЙ АНАЛИЗ Copilot CLI и Kilo Code

Полнота и корректность анализа кода: у Copilot CLI в среднем точнее, у Kilo Code быстрее, но чаще требовал корректировок.
Восстановление требований: выполнено обоими агентами, результаты различаются по полноте.
Модернизация и запуск: приложение запущено в обеих версиях.
Рефакторинг: выполнен обоими агентами.
Новая функциональность: реализована обоими агентами.
Автономность: Kilo Code работал стабильнее, Copilot CLI чаще требовал вмешательства из-за зависаний.
Скорость: Kilo Code — около 1 часа, Copilot CLI — около 2 часов.
Качество итогового результата: у Copilot CLI в среднем лучше, несмотря на более медленную работу и зависания.
